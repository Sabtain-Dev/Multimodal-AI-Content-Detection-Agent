# Model Selection

## Selection Criteria

For every candidate model, we will evaluate:

1. Task
2. Modality
3. Architecture
4. Training dataset
5. Languages
6. Model size
7. Input requirements
8. Output format
9. Evaluation metrics
10. License
11. Inference requirements
12. Known limitations
